# Larkspur Corte Madera Bicycle Alliance website

Static public website for the Larkspur Corte Madera Bicycle Alliance.

The site has no database or admin area. Content lives in `content/site-content.json`, images live in `public/`, and `npm run build` produces the deployable site in `out/`.

See `docs/OPERATIONS.md` for launch requirements and the maintenance checklist.
